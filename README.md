# Student-Details-Management-System

A menu-driven program that helps storing student details and perform various functions on it.
It is built using Python, OOP , and SQLITE3.

This project demonstrate a simple authentication system. The password mechanism is implemented only for demonstration purpose.
password = 1234

Features:
1. Admin Authentication
2. Add Student Details
3. Searching a Specific Student
4. View all the records
5. Update Specific fields
6. Delete Student Record
7. Generate Rank list
8. Search students by Marks range
9. Shows Statistics
10. Unique roll number validation

Tools:
Python 
OOP
SQLITE3
